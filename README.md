
# Linux Server Deployment and Networking Guide

## About the Project
This project covers Linux administration, networking fundamentals, SSH security, and web server deployment as part of my Cloud Computing and DevOps internship at Codomax Digital Solutions.

## Project Objectives
- Learn Linux command-line operations.
- Understand file permissions, users, groups, and processes.
- Explore IP addressing, DNS, ports, and firewalls.
- Understand SSH and secure remote access.
- Deploy and test an Nginx web server on an Ubuntu server.

- Linux / Ubuntu

- TCP/IP and DNS
- Nginx
- Git and GitHub

## Security Best Practices
- Use secure SSH access.
- Allow only necessary network ports.
- Apply least-privilege permissions.
- Never upload passwords, private keys, or cloud credentials.

## Testing
The deployment guide describes how to check the Nginx service and test a local HTTP response. Practical results should be recorded after running the tests on an authorized server.
